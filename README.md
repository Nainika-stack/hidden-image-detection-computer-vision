# Hidden Image Detection using Computer Vision

This project was developed as part of an AI/ML (Computer Vision) internship assignment for NAFED.

The objective of the assignment was to analyze an image and identify hidden information using image processing and computer vision techniques.

## Features

* RGB Channel Analysis
* Least Significant Bit (LSB) Extraction
* Most Significant Bit (MSB) Analysis
* Bit Plane Slicing
* Contrast Enhancement
* Thresholding Techniques

## Technologies Used

* Python
* OpenCV
* NumPy
* Matplotlib

## Approach

The image was analyzed across multiple RGB channels and bit planes to inspect hidden pixel-level information. Image enhancement and thresholding techniques were applied to improve visibility of the embedded content.

## Output

Successfully recovered the hidden four-digit number from the image.

## Learning Outcomes

* Practical exposure to computer vision workflows
* Understanding of image steganography concepts
* Hands-on experience with OpenCV image processing techniques
* Bitwise image analysis using Python
